# Triangle Links

Triangle Links is a nine-hole golf playtest with a drawn swing, driveable carts, and Steam lobbies for up to four players.

## Play on Windows

1. Open **Releases** and download the Windows ZIP attached to the latest playtest.
2. Extract the entire ZIP and run `TriangleLinks.exe`.
3. Use the same build as everyone in your multiplayer lobby.

The [changelog](CHANGELOG.md) covers the original s&box prototype and subsequent Unreal playtests.
